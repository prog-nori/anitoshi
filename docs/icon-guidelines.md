# アイコン制作規則

独自制作のSVG。128×128 viewBox、#262a26 と #f3efdf の2色。直線的な輪郭と面による識別。グラデーション、毛並み、頬染め、まつ毛、光沢・表情は使用しない。

犬5種と猫を先に制作し、docs/icon-review.html の一覧をChromeで128/48px表示して統一感をレビューした（2026-10-30）。太いシルエット、余白、2色、縮小時の形の判別を確認した後に残り4種を制作。レビュー用のHTMLは静的記録で、本番アプリには含めない。

- チワワ：大きく開いた耳と短い顔。
- ダックス：長い胴と短い脚、垂れ耳。体格の単純拡大縮小にしない。
- 柴犬：三角耳、幅広い頬の面。
- ゴールデン：大きな垂れ耳、幅のある口元。
- グレートデーン：長い顔と縦方向の輪郭。
- 猫：横に張った頬と尖った耳。
- うさぎ：長い耳。ハムスター：小さい耳と頬。
- セキセイインコ：くちばしと翼の面。フェレット：マスク状の顔と細長い首。

SVGに文字・外部参照・スクリプトを含めない。動物名を伴う装飾画像はalt="" / aria-hidden。カードは44px以上。色だけに頼らず、選択マーク・境界・aria-pressedで状態を表す。画像読み込み失敗は◇を表示し、名前による選択を維持する。
