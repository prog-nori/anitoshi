# アーキテクチャ

pnpm workspaceの2パッケージ。age-core → 外部依存なし。web → age-core公開エントリーポイントの一方向依存。

## コア

- domain: 年齢・リクエスト・結果・モデル・出典の型。
- animals / registry: 6種、犬5プロファイル。参照整合性の検証とメタデータ取得。
- models: 犬の研究式、5種の慣用換算表、猫の段階区分。
- evidence: 書誌・確認状況。年不明はnullで保持。
- conversion: 実行時入力検証、単位正規化、双方向変換、表示範囲制限。

戻り値の invalid-input は概念例に追加した状態。NaN/Infinity/負数/未知ID/方向/単位/プロファイルを返却コードで明示します。0は共通で拒否せず、猫は原点仮定の数値と子猫期、犬→人間は表示範囲外になります。入力範囲外の数値はnull。人間→動物は0〜128歳を受け付け、通常参考範囲外はmathematical-extension警告付きで逆算値を返す。isExtrapolated は「実際に返した数値が年齢または対象集団の外挿を含む」ことを示します。犬ペルソナの参考適用はtrue、範囲外で数値を返さない場合はfalseです。profileId省略のdogは研究対象モデル自体を意味し、全犬種への一般化を保証しません。

モデル・Registryは内部データを公開せず、取得APIはコピーを返します。関数は時計・HTTP・ストレージにアクセスしません。出典確認日は静的メタデータです。TypeScriptのlibはES2022のみ（DOMなし）。NodeNextの.js指定で、生成ESMをNodeから直接読めます。

## Web

固定のUIコンポーネントを表示用Registryで駆動。personasはコアの一覧から生成し、名前・SVGを合成。Vite globはSVGを読むWeb側にのみ存在します。アイコン欠落は◇へフォールバックし、動物名は常に残ります。

adapters/conversion.ts が文字列入力を検証し、ドメインのコードを日本語表示へ変換。数値の丸めはIntl.NumberFormatで最大小数1桁。1年未満の結果は月単位で表示（コアは年単位の未丸め値を保持）。年齢空欄は計算しません。年/月と方向の変更時は入力した数値を維持し、そのラベルと解釈を切り替えます。

ライフステージは人間との数値対応と分けています。未対応も通常の結果として表示。結果見出しだけをaria-liveで通知し、長い注意書き・出典の繰り返し読み上げを避けます。

React/Vite/TailwindはWebにのみ依存。NeoBrutalismの共通部品とデザイントークンは独自制作し、外部UIライブラリのコードはコピーしていません。主要依存はMIT、PlaywrightはApache-2.0。lockfileで再現性を確保しています。

## 慣用表エンジン

ModelMetadata.tableの掲載点を使う共通の双方向区分線形補間。動物追加時にconversionへ種別分岐を追加する必要はない。掲載点をRegistryで検証し、取得APIはコピーを返す。幼齢側の原点仮定は掲載点配列に追加せず、範囲外の別計算として警告する。猫の段階のみ、実年齢入力時に併記する。
